# RacLink Portfolio Projects: Apps Built with RacLink and ChatGPT Free

**RacLink Portfolio Projects is an open-source collection of real, working projects built with [RacLink](https://raclink.si) and the free tier of ChatGPT.** Each folder is a complete project you can read, run, fork and learn from. The repo is a public record of what you can ship using RacLink, with no paid AI plan required.

## What is this repository?

This repository stores projects made with **RacLink** ([raclink.si](https://raclink.si)), using OpenAI's free ChatGPT tier as the AI assistant. It exists to show developers, founders and builders what is possible when RacLink is paired with a free AI tool.

It is for you if you want to:

- See real examples of projects built with RacLink
- Learn how to build with a free AI assistant instead of a paid one
- Fork a starting point for your own Next.js and TypeScript project
- Judge RacLink by what has been built with it

## Tech stack

- **Platform:** [RacLink](https://raclink.si)
- **AI assistant:** ChatGPT (free tier)
- **Frontend:** Next.js (App Router), React
- **Language:** TypeScript (about 97% of the codebase), CSS
- **Package managers:** npm, yarn, pnpm or bun

## Quick start

Clone the repo and run any project locally. Example with Veltrix:

```bash
git clone https://github.com/Betavoid-nuke/RackLink-Portfolio-Projects.git
cd RackLink-Portfolio-Projects/veltrix
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Frequently asked questions

### What is RacLink?
RacLink is a platform at [raclink.si](https://raclink.si). This repository collects projects built with it.

### Can I really build projects with the free version of ChatGPT?
Yes. Every project here was built using ChatGPT's free tier together with RacLink, so you do not need a paid AI subscription to follow along.

### Can I use these projects as a starter template?
Yes. Fork the repo, copy a project folder, and adapt it. Each project is a standard Next.js app.

### How do I run a project?
Open the project folder, run `npm install`, then `npm run dev`, and visit `http://localhost:3000`.

### Can I contribute or suggest a project?
Yes. Open an [issue](../../issues) or a pull request.
